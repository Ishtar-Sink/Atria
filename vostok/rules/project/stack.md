# Stack

Define as tecnologias, versões e bibliotecas adotadas no Atria.

[project/stack-01]: Frontend em React com Vite e TypeScript em modo `strict`.
[project/stack-02]: Backend em Rust estável, edição 2024.
[project/stack-03]: HTTP com `axum` sobre `tokio`.
[project/stack-04]: Banco PostgreSQL, acessado com `sqlx` e queries checadas na compilação.
[project/stack-05]: A busca global usa a busca full-text do PostgreSQL (`tsvector`, `unaccent`, `pg_trgm`); um motor de busca externo só entra com decisão registrada.
[project/stack-06]: pnpm como gerenciador de pacotes, Node 22 ou superior.
[project/stack-07]: Rotas com TanStack Router e dados do servidor com TanStack Query.
[project/stack-08]: Formulários com `react-hook-form` e validação com `zod`.
[project/stack-09]: Fontes Outfit e Inter servidas pelo próprio app, nunca por CDN.
[project/stack-10]: Licença AGPL-3.0.
[project/stack-11]: PDFs e capas guardados num armazenamento local configurável, atrás de uma interface que permite trocar por um storage compatível com S3.
[project/stack-12]: Dependência nova só com justificativa registrada na tarefa.
