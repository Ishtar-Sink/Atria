# Idioma

Define as regras de idioma para o agente.

[project/language-01]: Conteúdo de documentações em `pt-br`.
[project/language-02]: Nome de documentações em `pt-br`.
[project/language-03]: Nome de arquivos de código em `en`.
[project/language-04]: Código em `en`.
[project/language-05]: Comentários em `pt-br`.

[project/language-06]: Textos da interface em `pt-br`, centralizados em arquivos de tradução, nunca literais nos componentes, para permitir outros idiomas.
[project/language-07]: Termos do domínio no código em `en`, com um glossário pt-br ↔ en na documentação (ex.: Diário ↔ `JournalEntry`, Acervo ↔ `Library`, Movimentação ↔ `Transaction`).
[project/language-08]: Erros da API com código estável em `en` (ex.: `invite_expired`); a mensagem exibida ao usuário vem da tradução no frontend.
